The practical is in preparation

The second 45-minute session will apply the lecture's reasoning framework to MnMT4. The worksheet, validated input files and any precomputed model outputs will appear here when ready; none are being presented as complete today.

Known case inputs

The case protein is MnMT4, UniProt accession V5X766, with SAM as cofactor and 3-OPC as a substrate input. A smaller-substrate comparison may be added; the activity itself has not yet been specified.

No MnMT4 structure, nearest structural neighbour, residue correspondence, ligand pose, reaction-geometry measurement or design answer is disclosed here. Those remain questions for the practical rather than worked lecture results.

Prepare your workstation

Have PyMOL available and try the non-MnMT4 examples in the downloadable visualisation toolkit. The resource directory provides the official tool and documentation links; no live GPU prediction or paid account is required merely to view the course materials.

What will be added

  • A student worksheet with tested instructions.
  • Approved input structures and molecular definitions.
  • Clearly labelled precomputed outputs where live computation is impractical.
  • An offline fallback and an evidence-based submission template.

The current lecture's conclusion rubric is already available: two defensible observations, one unresolved inference and one discriminating experiment. It is a general reasoning aid, not an answer key for this unfinished activity.
